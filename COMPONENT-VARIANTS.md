# Component Variants — Phase 2.5

| Component | Variants | Responsive rule |
| --- | --- | --- |
| Button | Primary, secondary outline, text link, icon/back-to-top | CTA groups stack full-width on mobile. |
| Navigation | Desktop links, services disclosure, mobile drawer | Collapse below 1024 px; no horizontal scrolling navigation. |
| Card | Service, value, conditional project/empty, article placeholder | 3 columns desktop, 2 tablet, 1 mobile. |
| CTA band | Deep Blue, light fallback | Copy/action stack on mobile. |
| Form feedback | Error, success, loading (specified), system failure | Full-width within form, message is not colour-only. |
| Badge | Neutral conditional label, category label | Must not be sole source of status. |
| Filter | Default, selected, focus | Wrap on small screens; keyboard-operable. |

No additional brand colours, radius values, or shadow styles are introduced by these variants.
