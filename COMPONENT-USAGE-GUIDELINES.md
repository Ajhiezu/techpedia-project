# Component Usage Guidelines — Phase 2.5

1. Use one filled primary CTA per decision group; use outline/link styling for an alternative route.
2. A whole card is interactive only if it has one destination. Otherwise use an explicit link.
3. Use native form controls unless a custom alternative materially improves accessibility.
4. Do not use cards as decorative wrappers for every paragraph.
5. Use conditional/empty states for absent portfolio, testimonial, technology, and team data—never public-looking fake cards.
6. Preserve 44 px target sizes, visible focus, label-before-control pattern, and DOM reading order at all breakpoints.
7. Respect reduced motion; motion may reinforce a state but never convey meaning alone.
