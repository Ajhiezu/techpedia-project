# Service Detail Pages — High-Fidelity Design

## Shared Page Frame

Every Service Detail uses the shared Header, Footer, 12/8/4 grid, 96/72/56 px section rhythm, and breadcrumb `Services / [Service]`. The page sequence is constant for findability, while visual metaphor, problem framing, feature modules, and CTA vary by service.

```text
HEADER + BREADCRUMB
SERVICE HERO (copy 7/12 + service-specific visual 5/12)
PROBLEM STATEMENT
SOLUTION OVERVIEW
KEY FEATURES / SCOPE
BENEFITS
DEVELOPMENT PROCESS
TECHNOLOGY CONSIDERATIONS (TBD until confirmed)
SERVICE FAQ
FINAL CTA
FOOTER
```

## Shared Process, FAQ & CTA

The process section uses Discovery → Planning → Design → Development → Testing → Deployment as an adaptable visual model. It must not communicate a fixed duration, methodology, SLA, integration, or outcome until the relevant policy and scope are confirmed.

Each page ends on a Deep Blue CTA band with the service-specific CTA plus secondary `View All Services`. FAQ answers remain policy-safe: explain discovery and scope, not unconfirmed price, turnaround, platform, or support promises.
