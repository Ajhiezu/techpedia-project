# Moodboard — Techpedia Project

## Mood Statement

**Calm authority for practical digital progress.**

The moodboard translates the Phase 1 brand into a light, disciplined, blue-led interface. It is intentionally functional: each reference board informs a decision for UI design rather than serving as decoration.

## 3. Visual Motifs

| Motif | Intended use | Emotional contribution |
| --- | --- | --- |
| Modular interface panels | Hero/service supporting visual, product-related sections. | Makes software capability tangible without fake case studies. |
| Process line / numbered steps | Work Process, About, service pages. | Signals a clear, managed way of working. |
| Connected nodes / data paths | ERP, API, or system-integration explanations. | Suggests systems thinking, not abstract “digital” noise. |
| Editorial image crop | About or selected service section where authentic imagery is available. | Adds human warmth while remaining professional. |
| Blue focus plane | CTA band, selected card, diagram highlight. | Directs attention with brand consistency. |

## 4. Textural & Shape Rules

- Use a fine border and quiet shadow as the principal depth cue.
- Use 10 px radius for standard surfaces and 16 px for modal/CTA emphasis, per token system.
- Keep geometric motifs rectangular, grid-aligned, and low contrast.
- A single faint blueprint/grid texture may be used behind a hero visual only if it does not compromise text contrast or readability.
- Do not use glassmorphism, luminous neon, aurora gradients, or oversized blurry blobs.

## 5. Moodboard “Do / Avoid”

| Keep | Avoid |
| --- | --- |
| One decisive hero visual with a clear business purpose. | Multiple unrelated hero graphics competing with copy. |
| Interface-like diagrams that explain a concept. | Decorative pseudo-code, random graphs, or invented metrics. |
| Calm light surfaces with precise blue emphasis. | Full-page dark mode or blue saturation across most surfaces. |
| Authentic, permitted imagery when available. | Generic stock photos that imply a fabricated company scale. |
| Quiet micro-interactions. | Scrolljacking, parallax overload, auto-playing carousels. |

## 6. Application by Page Type

| Page type | Mood expression |
| --- | --- |
| Home | Strong type-led hero + modular technology visual; broad whitespace and clear route to Services. |
| Service detail | Problem/solution structure with small functional diagrams or scope modules. |
| Portfolio | Minimal gallery; image/output leads only when project assets are valid. |
| About / Process | Editorial narrative, step system, and human/contextual visual only if permitted. |
| Insights | Reading-first layout, restrained category markers, and useful diagrams only when they clarify the article. |
| Contact | Calm, low-friction form surface with blue submit action and minimal distractions. |
