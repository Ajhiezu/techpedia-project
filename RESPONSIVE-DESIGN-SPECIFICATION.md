# Responsive Design Specification — Phase 2.6

| Viewport | Grid / layout | Key behavior |
| --- | --- | --- |
| 320–767 px | 4 columns, 16–24 px margins, 16 px gutter | One-column reading flow; menu drawer; full-width CTA groups; vertical process. |
| 768–1023 px | 8 columns, 32 px+ margins, 20 px gutter | Two-column cards where comfortable; hero may stack. |
| 1024–1439 px | Fluid desktop composition | Full navigation when it fits; 2-column hero; grids may remain 2–3 columns. |
| 1440 px+ | 12 columns, 1200 px maximum content container | Whitespace increases, content width does not. |

The prototype applies a 1024 px navigation/layout transition to protect the six-item header. The Phase 1 content-first responsive principles override device labels when content requires an earlier change.
