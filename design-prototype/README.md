# Techpedia Project — Phase 2 Prototype

This is an isolated, static UI/UX design prototype. It is **not** a production application and has no backend, database, API, analytics, or data submission.

## Open locally

Open `index.html` in a modern browser. The prototype uses hash routes, so it also works without a local server.

## Included flows

- Home → Services → Service Detail → Contact
- Home → Portfolio fallback → Contact
- Home → Insights fallback → Services
- Contact form validation, prototype success state, and prototype failure state
- Responsive desktop/mobile navigation, services disclosure, FAQ accordions, filters, legal draft pages, and 404

Portfolio, case study, testimonial, technology-stack, team, contact-route, and editorial content are deliberately represented by transparent fallbacks until valid and approved content is provided.
