# Desktop Design Guidelines — Phase 2.6

- Use a maximum 1200 px container and 12-column visual rhythm.
- Hero and split sections use 7/5 or balanced 6/6 columns with generous whitespace.
- Service cards use a 3-column grid; long card copy must grow instead of clipping.
- Header has one filled CTA; dropdown is click/keyboard operable and `/services` remains a direct fallback.
- Avoid widening body content merely because a large desktop is available.
