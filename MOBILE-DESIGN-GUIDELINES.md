# Mobile Design Guidelines — Phase 2.6

- Preserve copy → visual order in hero and content → action order in every section.
- Menu is a labelled drawer, not a horizontally scrolling navigation bar.
- Buttons stack before collision and retain 44 px touch targets.
- Cards become one column; process becomes vertical; FAQ stays full-width accordion.
- No fixed card, input, image, or CTA width exceeds the content container.
- Keep body text at 16 px minimum and honor reduced motion.
