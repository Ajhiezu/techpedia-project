# Route Structure

Routes are hash-based for static hosting: `/`, `/services`, `/services/:slug`, `/portfolio`, `/about`, `/process`, `/insights`, `/insights/:slug`, `/contact`, `/faq`, `/privacy-policy`, `/terms`. Unknown hashes render the 404 state. Six service slugs are implemented: `website-development`, `e-commerce-development`, `custom-software-development`, `erp-business-solutions`, `ui-ux-design`, and `maintenance-it-support`.
